Maternal Mortality Global Dashboard

Interactive Power BI dashboard for analyzing global maternal mortality patterns and country-wise mortality trends from 2014 to 2023.

Overview

The Maternal Mortality Global Dashboard is an interactive Power BI project designed to analyze maternal mortality data across different countries and years. The dashboard presents important statistics through interactive charts, cards, maps and country-wise comparisons.

The Problem

Maternal mortality data can be difficult to understand when presented only through raw datasets. This project focuses on transforming the data into meaningful visual insights that make global maternal mortality patterns easier to analyze and understand.

Approach

01

Collected and prepared maternal mortality data covering multiple countries and years.

02

Created interactive Power BI visuals to compare maternal mortality across countries and identify yearly trends.

03

Designed a dashboard with KPI cards, charts, country filters, map visualization and ranking-based analysis.
